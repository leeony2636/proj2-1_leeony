# 세션·입장 관리 개발 가이드

## 현재 구현

`POST /api/sessions`가 `theme_id`, `team_id`를 받아 임시 입장 payload를 반환한다.
`LocalRuntime`은 세션의 시작 시각, 현재 퍼즐, 해결 수, 종료 상태를 관리한다.

## 규칙

- P0에서는 QR 대신 임시 `session_id`와 `team_id`를 사용한다.
- 남은 시간과 진도는 고객 입력을 신뢰하지 않고 서버 세션에서 계산한다.
- 다른 팀의 세션은 조회·변경할 수 없다.
- 세션 종료·만료 후 힌트를 제공하지 않는다.

## 테스트

세션 생성/조회, 팀 불일치 거부, 종료 세션 차단, 퍼즐 해결 후 진도 갱신을 검증한다.

## 후속

서명 토큰·인증과 QR 입장을 추가하되, 현재 API schema와 권한 경계를 유지한다.
